AI + Figma MCP + Tokens Studio

Complete Beginner Guide 5 min read
Goal

Create a professional Figma Design System using AI, Figma MCP, and the Tokens Studio plugin.

1 Step 1 - Enable Figma MCP

Open your Figma file. In the right sidebar, scroll to the bottom and locate the MCP section. Ensure your MCP connection is active.

2 Step 2 - Connect Any AI

Click the MCP settings icon. Choose Other agents and copy the MCP server configuration.

Paste it into any AI that supports MCP (ChatGPT, Claude, Cursor, Manus, etc.).

3 Step 3 - Generate Personal Access Token

In Figma Home go to Profile → Settings → Security. Under Personal access tokens, create a new token.

  • Token Name: AI Name (ChatGPT / Claude / Manus)
  • Duration: 1 day, 30 days or 90 days
  • Permissions: Uncheck only Profile Information; keep the remaining permissions required by your workflow.

Copy the generated token and provide it to your AI when requested.

4 Step 4 - Test the Connection

Verify that the AI can successfully read from your Figma file by using the following prompt:

Prompt 
Can you access my connected Figma project? List all pages, frames and styles you can inspect.

5 Step 5 - Extract Design Tokens

Once the connection is verified, ask the AI to extract your design variables into a structured format.

Prompt 
Analyze my Figma file and extract reusable Colors, Typography, Spacing, Radius, Shadows and Opacity as design tokens.
Important Note

If the AI cannot directly create Figma Variables, ask it to generate a Design Token JSON compatible with Tokens Studio (DTCG format).

Final Prompt

Use this comprehensive prompt to get the exact output needed for Tokens Studio:

Prompt 
Analyze my Figma file. Generate a complete Design Token JSON for Tokens Studio including Colors, Typography, Spacing, Radius, Shadows and Opacity. Use semantic naming conventions and output only valid JSON.

Final Workflow Summary

End-to-End Process

Figma Design → MCP → AI Analysis → Design Token JSON → Tokens Studio Import → Export to Native Figma Variables → Build Components.
